# A draft the maintainers already know links to the request

## Problem Statement
The known-fingerprints file that each release ships: accepting or declining a group on the triage screen adds its fingerprint and issue link to a committed file in the repository, once per fingerprint and nothing else from the requests, and every installation receives it on update. When a friction's fingerprint is on the shipped list, drafting produces no sendable draft but a line saying 'already known to the CTOC maintainers' with the link and the release that recorded it, with no network lookup. No online model call; Windows, macOS and Linux.
