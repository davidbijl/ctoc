# A blocking scan stops any request carrying private data

## Problem Statement
The personal-data scan that cannot be switched off and blocks sending until the human removes every hit: the home folder and account name from the operating system, the git user name and e-mail, the project's folder and repository names, every path outside CTOC's own files in Windows, macOS and Linux shapes, any e-mail address, and every credential the existing SecretsScanner in src/lib/secrets-scanner.js recognises. A refusal names the kind of item and its line and never repeats the item, not even the scanner's redacted match form, in any message or log. No setting, flag or environment variable skips a check. No online model call. Its first live caller is the showing and sending stub.
